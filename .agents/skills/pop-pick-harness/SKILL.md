# 팝픽 하네스

팝픽 프론트엔드 작업을 시작할 때 밟는 공통 절차를 담는 스킬이다. 아직 절차 본문은 채우지 않았다. 아래는 채울 항목의 목록이다.

## 담을 것

**작업 시작 시 확인할 문서.** 루트 `AGENTS.md`와 `docs/product/ROADMAP.md`, 그리고 미결정 항목 목록. 어느 문서를 어떤 순서로 읽는지와 읽은 뒤 무엇을 확인하는지를 적는다.

**게이트 순서.** 구현이 끝난 뒤 돌리는 검사와 그 순서. 지금은 `pnpm type:check`를 먼저, 그다음 `pnpm build`, 마지막에 `pnpm lint`와 `pnpm format:check`다. 루트 `AGENTS.md`의 순서와 같다. 테스트 도구를 도입하면 그 실행 명령이 여기에 더해진다.

**미결정 항목을 만났을 때의 절차.** 기능 범위와 API 규약, 디자인 토큰처럼 아직 정해지지 않은 것을 작업 중에 만나면 기본값을 채우지 않고 묻는다. 무엇이 불확실한지와 어느 결정을 기다리는지를 구체적으로 적어 사용자에게 넘기는 방법을 여기 적는다.

## 채우는 시점

8/30 정기회의와 개발자 논의에서 기능 범위와 API 규약, 팀 공통 브랜치 전략이 확정된 뒤에 위 세 항목을 채운다. 그 전에 이 스킬이 호출되면 아직 절차가 없다고 답하고 위 목록을 보여준다.

## 룰과의 관계

룰은 세션마다 늘 로드되고 이 스킬은 요청이 위 description과 맞을 때만 붙는다. 늘 지켜야 하는 것은 `.agents/rules/`와 루트 `AGENTS.md`에 두고, 여기에는 작업 시작이라는 한 시점에만 쓰는 절차를 둔다.
