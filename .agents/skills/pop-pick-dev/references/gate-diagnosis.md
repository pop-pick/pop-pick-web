# 게이트가 실패할 때

게이트 명령과 순서는 `change-process.md`의 게이트 절이 정본이다. 여기는 자주 걸리는 원인이다.

## type:check 와 build

`next.config.ts`가 `API_BASE_URL`이 비어 있으면 예외를 낸다. `pnpm type:check`도 `next typegen`을 먼저 돌려 설정 파일을 읽으므로 같은 오류로 실패한다. 로컬은 `.env.local`이나 `.env`에, CI는 워크플로의 `env`에, 배포는 Vercel 프로젝트 환경 변수에 둔다.

## lint 와 format:check

포맷이 걸리면 걸린 파일만 지정해 `pnpm exec prettier --write <파일>`을 돌린다. `pnpm format`은 저장소 전체를 고쳐 이번 작업과 무관한 파일까지 바꾼다.

## harness:check

| 걸린 검사          | 원인과 고치는 법                                                                           |
| ------------------ | ------------------------------------------------------------------------------------------ |
| 컨벤션 검사        | 걸린 룰 파일의 대신 하는 것 절을 보고 옮긴다                                               |
| 생성물 대조        | `.agents/` 원본을 고치고 생성기를 안 돌렸다. `pnpm harness:sync`                           |
| 커밋할 생성물 대조 | 원본만 스테이징했다. 생성기가 바꾼 `.claude/`와 `.codex/`, `AGENTS.md`를 함께 스테이징한다 |
| 회귀 테스트        | 검사나 훅을 고쳤는데 픽스처가 기대와 다르다. 검사와 픽스처 중 어느 쪽이 맞는지 본다        |
