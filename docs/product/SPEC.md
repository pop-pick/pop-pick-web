# 팝픽 기능 명세

기능이 정확히 어떻게 동작하는지 적는 문서다. 왜 만드는지는 PRD.md가 맡는다. 화면이 잡히면 채우고 이 안내 문단을 지운다. 구현하다 규칙이 바뀌면 이 문서를 먼저 고치고 코드를 맞춘다.

## 용어

프로젝트 고유 용어를 정의한다. 코드 식별자와의 대응을 함께 적어 문서와 코드를 오갈 수 있게 한다. 아래는 원안 용어의 후보이고 코드 식별자는 아직 없다.

| 용어         | 뜻                                                                                        | 코드에서 |
| ------------ | ----------------------------------------------------------------------------------------- | -------- |
| 팝업         | 기간과 장소가 정해진 팝업 스토어. 팝픽이 다루는 기본 단위                                 |          |
| 플래너(코스) | 지역과 가용 시간, 동행, 취향을 넣으면 나오는 방문 순서와 예상 소요시간이 담긴 원데이 코스 |          |
| 찜           | 팝업을 관심 팝업으로 저장하는 것                                                          |          |

## 기능 상세

기능마다 아래 절을 복사해 채운다.

### {기능 이름}

**동작 규칙.** 정상 흐름을 순서대로 적는다.

**화면 흐름.** 어느 화면에서 시작해 어디로 가는지 Next.js App Router 라우트 경로로 적는다. `src/app` 아래 세그먼트와 하나씩 대응한다.

**경계 조건.** 비어 있을 때와 실패할 때, 중간에 끊길 때 무엇이 보이는지 적는다.

**데이터.** 무엇을 어디에 저장하는지 적는다. 팝업 데이터 출처(공개 API, 제휴, 수기 입력 중)는 미결정이라 8/30 정기회의에서 출처가 정해진 뒤 채운다.
