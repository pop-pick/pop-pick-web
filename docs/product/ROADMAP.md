# 팝픽 로드맵

무엇을 어떤 순서로 만드는지 적는다. PRD.md의 범위를 마일스톤으로 자른 것이다. 버전은 프론트엔드 내부 주차 목표다.

## 마일스톤

한 마일스톤은 목표 한 문장으로 요약되어야 한다. 요약이 안 되면 쪼갠다.

| 버전 | 기간              | 목표                                                     | 포함 기능                                           | 상태    |
| ---- | ----------------- | -------------------------------------------------------- | --------------------------------------------------- | ------- |
| 0.1  | 1주차 (8/24~8/30) | 스택 확정, 빈 페이지 Vercel 배포, 공통 레이어 착수       | 없음. 기반 작업이다                                 | 완료    |
| 0.2  | 2주차 (8/31~9/6)  | 공통 레이어 완성, 핵심 화면 1개 동작                     | 온보딩 폼과 소셜 로그인 콜백 선작업, 지도 표시 모듈 | 진행 중 |
| 0.3  | 3주차 (9/7~9/13)  | 주요 화면 구현, API 연동 시작. 페이지 단위 분담으로 전환 |                                                     | 예정    |
| 0.5  | 4주차 (9/14~9/20) | 핵심 기능 전부 동작. 스타일 미완성 허용                  |                                                     | 예정    |
| 0.9  | 5주차 (9/21~9/27) | 스타일 마감, 엣지 케이스                                 |                                                     | 예정    |
| 1.0  | 6주차 (9/28~10/4) | 버그 처리, 2026-10-04(일) 출시                           |                                                     | 예정    |
| 1.1  | 10/5~10/16        | QA와 고도화, 발표 준비. 2026-10-17(토) 데모데이          |                                                     | 예정    |

기능을 만드는 순서는 온보딩 취향 수집, 저장, 추천 동선이다. 기능 목록은 PRD.md에 있다. 3주차 뒤의 기능별 주차 배정은 미정이라 포함 기능 열이 비어 있다.

0.2에서 공통 레이어와 지도 표시 모듈(`src/shared/lib/kakao-map`)을 만든다. 핵심 화면은 아직 없다.

공식 프로그램 일정은 API 연동을 개발 5~6주차에 둔다. 프론트엔드는 이를 3주차로 앞당긴다. 연동은 늘 예상보다 오래 걸린다. 5주차에 시작해 그 시점에 문제가 나면 10/4 마감까지 조정할 시간이 2주뿐이다.
