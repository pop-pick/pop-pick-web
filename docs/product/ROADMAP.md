# 팝픽 로드맵

무엇을 어떤 순서로 만드는지 적는다. PRD.md의 범위를 마일스톤으로 자른 것이다. 버전은 프론트엔드 내부 주차 목표다. 포함 기능 열은 8/30 정기회의에서 기능 범위가 확정된 뒤 채운다.

## 마일스톤

한 마일스톤은 목표 한 문장으로 요약되어야 한다. 요약이 안 되면 쪼갠다.

| 버전 | 기간              | 목표                                               | 포함 기능 | 상태    |
| ---- | ----------------- | -------------------------------------------------- | --------- | ------- |
| 0.1  | 1주차 (8/24~8/30) | 스택 확정, 빈 페이지 Vercel 배포, 공통 레이어 착수 |           | 진행 중 |
| 0.2  | 2주차 (8/31~9/6)  | 공통 레이어 완성, 핵심 화면 1개 동작               |           | 예정    |
| 0.3  | 3주차 (9/7~9/13)  | 주요 화면 구현, API 연동 시작                      |           | 예정    |
| 0.5  | 4주차 (9/14~9/20) | 핵심 기능 전부 동작. 스타일 미완성 허용            |           | 예정    |

| 1.1  | 10/5~10/16        | QA와 고도화, 발표 준비. 2026-10-17(토) 데모데이    |           | 예정    |

2026-08-29 기준 0.1의 셋 중 스택 확정과 빈 페이지 Vercel 배포가 끝났고 8/29에 공통 레이어도 착수했다. 의존성 설치와 `src/shared` 구조, API 레이어와 디자인 시스템 안내가 들어갔고, create-next-app 첫 화면을 팝픽 소개 화면으로 바꾸고 첫 공용 컴포넌트 Button을 넣었다. 공통 레이어 완성은 0.2에서 한다. 프로덕션은 https://pop-pick-web.vercel.app 이다.

공식 프로그램 일정은 API 연동을 개발 5~6주차에 둔다. 프론트엔드는 이를 3주차로 앞당긴다. 연동은 늘 예상보다 오래 걸리고, 5주차에 시작해 그 시점에 문제가 나면 10/4 마감까지 조정할 시간이 2주뿐이다.
