# 팝픽 화면 명세

화면마다 무엇이 어떻게 놓이는지 적는다. 톤과 색은 DESIGN.md가 정하고 이 문서는 배치와 상태를 정한다. 화면의 정본은 PM이 관리하는 기획 피그잼 보드다. 상태(로딩, 비어 있을 때, 오류)와 인터랙션, 접근성 계약은 `docs/architecture/`의 기능 문서가 화면마다 적고 여기는 배치만 적는다.

## 화면 목록

경로와 화면, 로그인 여부는 `docs/product/SPEC.md`의 화면 흐름과 라우트 절에 있다. 하단 탭바는 모든 화면에 붙는다. 온보딩 세 단계는 `src/app/onboarding/[step]` 한 폴더가 받고 나머지는 세그먼트 폴더 하나에 화면 하나다.

## 화면 상세

배치는 기획 보드의 화면을 따른다. 여기는 화면에 없는 것과 화면과 다르게 하기로 한 것만 적는다.

### 랜딩

재방문자에게 매번 보일지는 미정이다.

### 온보딩

헤더에 뒤로 가기가 있고 진행 표시는 "1 / 3" 형태다. 아래에 "다음"과 "건너뛰기"가 나란히 놓이고 3단계는 "다음" 자리가 "시작하기"다. 버튼을 비활성으로 두지 않는다. 미입력과 완료 알럿은 SPEC의 온보딩 절에 있다.

### 로그인

카카오 버튼이 위이고 구글 버튼은 클라이언트 ID와 콜백이 없어 비활성으로 자리만 있다. 버튼 아래 고지문이 약관 동의를 갈음한다. 로그인 실패는 콜백 화면이 문구와 돌아가는 링크로 보인다.

### 로그인 완료

소셜 로그인이 외부에서 끝나고 돌아오므로 약관 동의 화면 없이 완료 화면만 둔다. 완료 문구와 다음 화면으로 가는 버튼 하나다. 온보딩으로 갈 때와 찜을 누르다 로그인한 때가 같은 화면을 지난다.

### 홈

회원 홈과 비회원 홈이 같은 경로를 쓰고 헤더 문구와 첫 섹션이 갈린다. 회원은 "{이름}님의 팝업 PICK" 롤링 세 칸과 AI 코스 생성 버튼, 비회원은 고정 문구와 취향 입력 배너다. 아래로 인기 팝업 상위 셋과 인기 지역 칩이 이어지고 둘은 회원과 비회원에게 같다. 카드의 평점과 리뷰 수는 값이 없으면 그리지 않는다.

### 탐색

검색바와 뷰 전환, 정렬이 지도 뷰와 목록 뷰 위에 공통으로 놓인다. 필터 칩은 두지 않는다. 홈의 지역 칩으로 들어왔을 때만 왼쪽에 지역 배지가 놓이고 누르면 지역이 풀린다. 지도 위에는 현재 위치 버튼이 오른쪽 아래, 위치 권한을 거부했을 때의 안내가 왼쪽 아래다. 지도 SDK가 통째로 실패하면 그릴 지도가 없어 지도 자리 전체가 오류 화면이 되고 다시 시도와 목록으로 보기 둘이 놓인다. 핀을 누르면 하단에 팝업 카드가 뜨고 현재 위치 버튼은 카드 위로 올라간다. "총 N곳"은 백엔드가 총 건수를 주기 전까지 그리지 않는다.

### 팝업 상세

전체 화면 페이지와 지도를 덮는 레이어 두 껍데기에 같은 본문이 들어간다. 화면에 없는 것 하나는 예약 링크다. `reservationUrl`이 있는 팝업만 정보 영역에 외부 링크 버튼이 놓인다. 하단 액션은 찜과 공유하기, "이 팝업으로 AI 코스 추천받기" 셋이다. 방문 후기 탭은 데이터가 오기 전까지 준비 중 상태다.

### 내 일정

플래너의 첫 화면이다. 탭 셋(다가오는 일정, 지난 일정, 취소된 일정)과 일정 카드 목록, 코스 만들기 버튼이다. 일정이 하나도 없으면 목록 자리에 코스를 만들러 가는 자리가 놓인다. 캘린더로 보낸 일정에는 배지가 붙는다.

### 코스 조건 입력

화면의 지역, 동행, 소요 시간, 토글 둘에 방문 날짜(달력)와 시작 시각(오전 9시부터 밤 10시)이 더해진다. 지역 목록은 성수, 여의도, 홍대, 신촌, 용산 다섯이다. 화면의 성수동, 한남동, 홍대와 신촌, 잠실과 다르며 지역 목록 통일 결정을 기다린다.

### 코스 생성 중

제목은 "코스를 만들고 있어요"이고 그 아래 "10초 정도 소요될 수 있어요"가 붙는다. 진행 카드에 막대와 체크 항목 셋이 있고 아래에 취소하기 버튼이 있다. 카드 위 아이콘은 카테고리 아이콘이 1초마다 바뀌는 애니메이션이다. 체크 항목은 서버가 단계를 보내는 것이 아니라 프론트가 시간으로 넘긴다. 실패하면 문구와 다시 시도, 조건 수정 버튼이 놓인다. 10초는 백엔드 측정 전의 임시값이라 바뀌면 화면과 코드를 같이 고친다.

### 코스 결과

지도 아래 총 도보 요약과 타임라인이 놓이고 하단에 캘린더 저장과 공유하기, 다시 만들기가 있다. 캘린더 저장은 버튼 둘이다. 구글 캘린더에 추가가 위, 캘린더 파일 받기가 아래다. 코스를 고치거나 되돌리는 버튼은 없다. 구간 소요시간을 조회하는 동안 구간마다 로딩 표시를 그리고 실패한 구간은 "소요시간 모름"이다. 화면의 연계 카페와 대기시간은 값이 없으면 그리지 않는다.

### 캘린더 저장 완료

화면의 "등록 완료"는 등록 여부를 우리가 알 수 없어 "캘린더로 보냈습니다"로 바꾼다. "저장된 일정 보기"는 플래너의 내 일정으로 간다. 화면에 남아 있는 "방문 전 알림받기"는 그리지 않는다. 알림을 넣지 않기로 했다.

### 마이페이지

탭 둘(찜한 팝업, 최근 본 팝업)에 각 탭의 개수가 붙는다. 저장한 코스는 플래너의 내 일정으로 옮겼다. 종료된 찜은 목록에서 지우지 않고 흐리게 보인다. 최근 본 팝업은 최신 다섯이다. 화면의 알림 설정은 그리지 않는다. 로그아웃과 이용 안내를 어디 두는지는 디자인 착수 전에 정한다.

## 공통 컴포넌트

두 화면 이상에서 쓰는 컴포넌트를 적는다. 코드는 `src/shared/ui`에 두고 디자인 시스템 담당 프론트엔드가 주인이다. 만드는 규칙은 `.agents/rules/ui.md`에 있다.

값은 전부 Tailwind 기본이다. 디자이너 시안이 오면 토큰과 클래스를 갈아 끼운다. 쓰는 화면은 설계에서 정한 자리이고 화면이 아직 뼈대라 놓이지 않은 것도 있다.

### 만든 것

| 컴포넌트          | 쓰는 화면                            | 규칙                                                                                                                         |
| ----------------- | ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| Badge             | 카드, 상세, 코스 목록                | tone neutral, accent, warning. 예약 유형, 카테고리, 정보 확인 중, 종료 임박, 캘린더에 보냄에 쓴다                            |
| BottomTabBar      | 모든 화면                            | 탭 넷. 현재 탭에 `aria-current="page"`                                                                                       |
| Button            | 화면 대부분                          | variant primary, secondary, ghost와 size md, lg. 키보드 포커스 표시가 있다                                                   |
| Chip              | 온보딩, 코스 조건, 홈 인기 지역      | 선택 여부를 `selected`로 받는다. 단일과 다중 선택은 부르는 쪽이 정한다                                                       |
| EmptyState        | 탐색 0건, 찜 목록, 코스 목록         | 제목과 설명, 선택 동작 하나                                                                                                  |
| IconButton        | 탐색 지도의 현재 위치와 카드 닫기    | 44px 원형. variant surface, ghost. 아이콘만 있어 `label`이 필수다                                                            |
| LinkButton        | 랜딩, 로그인, 오류와 없는 페이지     | Button과 같은 variant를 `next/link`에 입힌다                                                                                 |
| PlaceholderBox    | 카드 이미지, 지도 자리               | 이미지와 지도가 들어갈 자리를 라벨 붙은 빈 상자로 둔다. 시안과 지도가 들어오면 사라진다                                      |
| PopupCard         | 홈, 탐색 목록, 찜 목록, 최근 본 팝업 | `PopupCardItem`을 받아 배지와 팝업명, 지역과 종료일을 그린다. `showReason`이 추천 이유를 두 줄로 붙인다. 찜 버튼은 아직 없다 |
| ScreenPlaceholder | 아직 만들지 않은 화면 일곱           | 제목과 설명, 만들지 않았다는 문구. 화면을 채우면 사라진다                                                                    |
| SectionHeader     | 홈 추천 섹션과 인기 섹션             | 제목과 설명, 더 보기 링크                                                                                                    |
| Skeleton          | 탐색 준비 중, 로그인 확인 중         | 모양만 그리고 `aria-hidden`이다. 무엇을 기다리는지는 감싸는 쪽의 `role="status"` 문구가 알린다                               |

### 아직 후보

설계에서 두 화면 이상 쓰임이 확인됐고 그 화면을 만들 때 함께 만든다.

| 컴포넌트      | 쓰는 화면                         | 규칙                                                   |
| ------------- | --------------------------------- | ------------------------------------------------------ |
| BottomSheet   | 탐색 팝업 카드                    | 비모달                                                 |
| Tabs          | 상세, 내 일정, 마이페이지         | WAI-ARIA Tabs, URL과 동기                              |
| ErrorState    | 섹션 단위 실패, 지도 실패         | 문구와 다시 시도                                       |
| ConfirmDialog | 찜과 해제, 코스 삭제, 온보딩 알럿 | native `<dialog>`. 확인과 취소, 확인 하나 둘 다 받는다 |
