# 팝픽 화면 명세

화면마다 무엇이 어떻게 놓이는지 적는다. 톤과 색은 DESIGN.md가 정하고 이 문서는 배치와 상태를 정한다.

기능 범위는 8/30(일) 정기회의에서 확정한다. 그 뒤 와이어프레임이 나오면 화면 목록의 경로를 정하고 화면 상세를 채운다.

## 화면 목록

Next.js App Router의 라우트 경로를 기준으로 적는다. `src/app` 아래 세그먼트 폴더와 하나씩 대응한다.

`/` 홈 아래 네 행은 프론트엔드가 예상하는 화면이다. 목적은 PM 원안 기준이라 8/30(일) 기능 범위 확정 뒤 다시 맞춘다. 경로는 확정과 와이어프레임 뒤에 정한다.

| 경로 | 화면 이름        | 목적                                                                    | 비고                                 |
| ---- | ---------------- | ----------------------------------------------------------------------- | ------------------------------------ |
| /    | 홈               | 서비스가 무엇인지 한 문장으로 알리고 열릴 날을 보여준다. 8/29 임시 화면 | 기능이 열리면 조건 입력으로 이어진다 |
| 미정 | 조건 입력        | 지역과 가용 시간, 동행, 취향을 입력한다                                 | 폼                                   |
| 미정 | 코스 결과        | 추천 팝업과 방문 순서, 예상 소요시간을 지도와 타임라인으로 보여준다     | 핵심 화면. Kakao Map SDK를 쓴다      |
| 미정 | 팝업 상세        | 팝업 하나의 정보를 본다                                                 |                                      |
| 미정 | 팝업 목록과 탐색 | 지역과 카테고리로 팝업을 걸러 본다                                      | 필터링                               |

## 화면 상세

화면마다 아래 절을 복사해 채운다.

### {화면 이름} `{경로}`

**목적.** 이 화면에서 사용자가 이루는 일 하나를 적는다.

**구성.** 위에서 아래로 놓이는 요소를 순서대로 적는다.

**상태.** 로딩 중일 때와 비어 있을 때, 오류일 때 각각 무엇이 보이는지 적는다.

**인터랙션.** 클릭과 터치, 키보드 조작이 각각 무엇을 하는지 적는다. 모바일 퍼스트라 터치를 먼저 적는다. 키보드만으로도 조작할 수 있어야 한다.

## 반응형

모바일 세로를 기준으로 잡는다. 태블릿과 PC 폭에서 배치가 어떻게 달라지는지 화면마다 적는다. 기준 폭은 미정이고 DESIGN.md의 반응형 절과 맞춘다.

| 화면 | 태블릿 폭에서 달라지는 것 | PC 폭에서 달라지는 것 |
| ---- | ------------------------- | --------------------- |

## 공통 컴포넌트

두 화면 이상에서 쓰는 컴포넌트를 적는다. 처음부터 채우지 않고 두 번째 쓰임이 나올 때 올린다.

코드는 `src/shared/ui`에 두고 디자인 시스템 담당 프론트엔드가 주인이다. 시안 전에도 시작할 수 있는 기본 컴포넌트 후보로 Button, Input, Modal, Toast가 있다. 시안이 나오면 토큰과 맞춘다. 만드는 규칙과 폴더 안내는 `src/shared/ui/README.md`에 있다.

| 컴포넌트 | 쓰는 화면 | 규칙                                                                                                   |
| -------- | --------- | ------------------------------------------------------------------------------------------------------ |
| Button   | 홈        | `src/shared/ui/Button.tsx`. variant primary, secondary, ghost와 size md, lg. 키보드 포커스 표시가 있다 |
