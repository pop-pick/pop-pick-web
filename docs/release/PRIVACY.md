# 개인정보처리방침

서비스에 게시하는 개인정보처리방침의 원본이다. 실제 서비스가 수집하는 것과 한 항목도 다르면 안 된다. 수집 항목이 있는 SDK를 넣을 때마다 이 문서를 같이 고친다.

게시 위치는 미정이다. 서비스 안의 라우트(예를 들어 `/privacy`)로 둘지 별도 페이지로 둘지 정하지 않았다. 커스텀 도메인도 미정이라 게시 URL은 도메인이 정해진 뒤 적는다.

게시 URL: 미정

## 게시용 본문

아래를 채워 게시한다. 시행일 이후에 내용이 바뀌면 개정 이력을 남긴다.

팝픽(이하 "서비스")은 다음과 같이 개인정보를 처리한다.

### 수집하는 항목

소셜 로그인(구글, 네이버, 카카오)으로 사용자를 식별하므로 계정 정보를 받는다. 온보딩에서 성별과 인원수, 취향을 받는다. 알림 기능이 없어 연락 수단은 받지 않는다. 위치 정보는 받지 않고 브라우저 위치 권한도 요청하지 않는다.

| 항목                                    | 수집 방법                                          | 필수 여부      |
| --------------------------------------- | -------------------------------------------------- | -------------- |
| 소셜 로그인 계정 정보. 받는 필드는 미정 | 구글, 네이버, 카카오 로그인 때 제공자에게서 받는다 | 로그인 때 필수 |
| 성별, 인원수                            | 온보딩 화면에서 버튼으로 고른다                    | 미정           |
| 취향                                    | 온보딩 화면에서 자연어로 적는다                    | 미정           |
| 관심 팝업(찜) 목록                      | 서비스 이용 중 저장한다                            | 선택           |
| 서비스 이용 기록                        | 추천에 쓰기 위해 이용 중 기록한다. 항목은 미정     | 미정           |

캘린더 연동을 API로 할지 파일 내려받기로 할지 정해지지 않았다. API 연동이면 캘린더 접근 권한이 항목에 더해진다.

### 이용 목적

| 항목                                 | 목적                           |
| ------------------------------------ | ------------------------------ |
| 소셜 로그인 계정 정보                | 사용자 식별, 찜과 내 팝업 제공 |
| 성별, 인원수, 취향, 서비스 이용 기록 | AI 개인화 추천                 |
| 관심 팝업 목록                       | 내 팝업 화면 제공              |

### 보관 기간

미정이다. 탈퇴나 삭제 요청 시의 처리도 함께 정한다.

### 제3자 제공

미정이다. 캘린더 연동을 API로 하면 일정이 구글과 애플로 전송되므로 그때 적는다.

### 사용하는 외부 SDK와 호스팅

| SDK                     | 용도      | 해당 SDK가 수집하는 것 |
| ----------------------- | --------- | ---------------------- |
| 카카오맵 JavaScript SDK | 지도 표시 | 확인하지 못했다        |

도보 소요시간은 서버에서 카카오맵 REST API를 불러 받는다. 팝업 좌표만 보내고 사용자 정보는 보내지 않는다.

호스팅은 Vercel이다. 요청 로그에 남는 항목은 확인하지 못했다.
