# 개인정보처리방침

서비스에 게시하는 개인정보처리방침의 원본이다. 실제 서비스가 수집하는 것과 한 항목도 다르면 안 된다. 수집 항목이 있는 SDK를 넣을 때마다 이 문서를 같이 고친다.

게시 위치는 미정이다. 서비스 안의 라우트(예를 들어 `/privacy`)로 둘지 별도 페이지로 둘지 정하지 않았다. 커스텀 도메인도 미정이라 게시 URL은 도메인이 정해진 뒤 적는다.

게시 URL: 미정

## 게시용 본문

아래를 채워 게시한다. 시행일 이후에 내용이 바뀌면 개정 이력을 남긴다.

팝픽(이하 "서비스")은 다음과 같이 개인정보를 처리한다.

### 수집하는 항목

회원 기능과 알림 기능의 포함 여부는 8/30(일) 정기회의에서 정해진다. 그에 따라 항목이 생긴다. 알림이 들어가면 연락 수단 정보가, 회원이 들어가면 계정 정보가 생긴다. 둘 다 없으면 "수집하지 않는다"라고 적는다.

### 이용 목적

항목별로 무엇에 쓰는지 적는다.

### 보관 기간

언제 지우는지 적는다. 탈퇴나 삭제 요청 시의 처리도 함께 적는다.

### 제3자 제공

없으면 없다고 적는다.

### 사용하는 외부 SDK와 호스팅

| SDK           | 용도      | 해당 SDK가 수집하는 것 |
| ------------- | --------- | ---------------------- |
| Kakao Map SDK | 지도 표시 | 확인 뒤 기입           |

호스팅은 Vercel이다. 요청 로그에 남는 항목은 확인 뒤 기입한다.

### 문의처

담당 연락처를 정하면 적는다.

### 시행일
