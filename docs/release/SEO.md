# 검색 유입 운영

코드로 할 수 없는 SEO 작업을 적는다. 메타 태그와 Open Graph, sitemap.xml, robots.txt 같은 코드 쪽 작업은 마일스톤 0.9에 있고 일정은 `docs/product/ROADMAP.md`가 갖는다. 이 문서는 그 밖의 일만 다룬다.

항목마다 할 일과 담당, 상태를 적는다. 상태는 미정, 진행 중, 완료 중 하나다.

## 도메인과 DNS

커스텀 도메인은 미정이다. 팀이 구매하고 데모데이 전까지 DNS를 Vercel에 연결한다. 아래 절의 일은 대부분 도메인이 정해진 뒤 시작된다.

| 할 일                                                                                                              | 담당       | 상태 |
| ------------------------------------------------------------------------------------------------------------------ | ---------- | ---- |
| 도메인 구매                                                                                                        | 미정       | 미정 |
| DNS를 Vercel에 연결                                                                                                | 미정       | 미정 |
| 도메인이 정해지면 `src/app/layout.tsx`의 `metadata`에 `metadataBase`를 넣는다. 지금은 OG 이미지 주소가 상대 경로다 | 프론트엔드 | 미정 |

## 검색 엔진 등록

도메인이 정해진 뒤 진행한다. 소유권 확인은 메타 태그나 DNS 레코드로 한다. 메타 태그를 쓰면 `src/app/layout.tsx`의 `metadata`를 고쳐야 한다.

| 할 일                                     | 담당 | 상태 |
| ----------------------------------------- | ---- | ---- |
| Google Search Console 등록과 sitemap 제출 | 미정 | 미정 |
| 네이버 서치어드바이저 등록과 sitemap 제출 | 미정 | 미정 |

## 스위프 참가 혜택

스위프 참가 혜택에 SEO 지원과 유입 데이터 분석이 포함되어 있다. 구체 내용은 아직 확인하지 못했고 우선순위는 낮다.

| 할 일                                   | 담당 | 상태 |
| --------------------------------------- | ---- | ---- |
| SEO 지원 내용을 운영진에게 확인         | 미정 | 미정 |
| 유입 데이터 분석 내용을 운영진에게 확인 | 미정 | 미정 |

## Open Graph 이미지

이미지 원본은 시안 파일의 OG 프레임(1200x630)이고 `public/images/brand/og.png`에 있다. 문구와 크기는 `src/shared/model/site-metadata.ts`가 정한다. 파비콘은 시안의 심볼 로고로 만든 `public`의 `favicon.ico`와 `icon.svg`, `apple-icon.png`이고 `site-metadata.ts`의 `SITE_ICONS`가 루트 레이아웃 메타데이터에 경로를 적는다. 정적 이미지는 `public`에 둔다는 저장소 규칙을 따른다.

| --------------------------- | -------- | ---- |
| Open Graph 이미지 원본 수령 | 디자이너 | 완료 |
