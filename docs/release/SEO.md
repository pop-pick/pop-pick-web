# 검색 유입 운영

코드로 할 수 없는 SEO 작업을 적는다. 메타 태그와 Open Graph, sitemap.xml, robots.txt 같은 코드 쪽 작업은 라우팅 설계 때 함께 잡기로 했다. 이 문서는 그 밖의 일만 다룬다.

항목마다 할 일과 담당, 상태를 적는다. 상태는 미정, 진행 중, 완료 중 하나다.

## 도메인과 DNS

커스텀 도메인은 미정이다. 팀이 구매한다. 구매하면 DNS를 Vercel에 연결한다. 아래 절의 일은 대부분 도메인이 정해진 뒤 시작된다.

| 할 일               | 담당 | 상태 |
| ------------------- | ---- | ---- |
| 도메인 구매         | 미정 | 미정 |
| DNS를 Vercel에 연결 | 미정 | 미정 |

## 검색 엔진 등록

도메인이 정해진 뒤 진행한다. 소유권 확인은 메타 태그나 DNS 레코드로 한다. 메타 태그를 쓰면 코드 변경이 필요하니 라우팅 설계 담당과 맞춘다.

| 할 일                                     | 담당 | 상태 |
| ----------------------------------------- | ---- | ---- |
| Google Search Console 등록과 sitemap 제출 | 미정 | 미정 |
| 네이버 서치어드바이저 등록과 sitemap 제출 | 미정 | 미정 |

## 스위프 참가 혜택

스위프 참가 혜택에 SEO 지원과 유입 데이터 분석이 포함되어 있다. 구체 내용은 운영진에게 확인 뒤 적는다.

| 할 일                                   | 담당 | 상태 |
| --------------------------------------- | ---- | ---- |
| SEO 지원 내용을 운영진에게 확인         | 미정 | 미정 |
| 유입 데이터 분석 내용을 운영진에게 확인 | 미정 | 미정 |

## Open Graph 이미지

이미지 원본은 디자이너에게 받는다. 로고가 진행 중이라 로고가 나온 뒤 만든다. 이미지를 코드에 넣는 일은 라우팅 설계 쪽이다.

| 할 일                       | 담당     | 상태 |
| --------------------------- | -------- | ---- |
| Open Graph 이미지 원본 수령 | 디자이너 | 미정 |
